Glossary of Tantra terms

Plain-language definitions of the words Tantra uses across calendar campaigns, cold email, sending, and personalization.

beginner · 6 min read · Updated Jul 25, 2026

Overview#

This page defines the terms you see across Tantra. Entries are grouped alphabetically. Where a full article covers a term, a link takes you there. Read this alongside What is Tantra and Calendar campaigns vs cold email.

A#

API key. A secret token you generate to call the Tantra API or connect the Tantra MCP server without signing in through the browser. You copy the key once at creation and store it yourself. See Create and manage API keys.

B#

Batch. A chunk of contacts that a calendar campaign processes together. A batch holds up to 200 attendees, and batches for the same event are scheduled 24 hours apart so Google does not flag a sudden flood of invitations. See How invitations are batched and sent.

C#

Calendar campaign. Tantra's original outreach engine. Instead of sending an email, it creates a Google Calendar event and adds your prospects as attendees, so Google delivers the invitation to their inbox. Their RSVP is the engagement signal. See What are calendar campaigns.

Click tracking. Rewriting the links in your emails so Tantra records when a recipient clicks one. Tantra tracks clicks only. It does not track opens. See How click tracking works.

Cold email. Tantra's second engine. It sends multi-step email sequences from your own mailboxes through the Gmail API, with per-sender daily and hourly limits. See What is cold email outreach.

Connected / disconnected. The state of a sender. Connected means Tantra found a working service account that can send as that mailbox. Disconnected means the link stopped working, so that sender is skipped until you fix it. See Sender connection states explained.

D#

Distribution plan. The internal work queue that drives a calendar campaign. It tracks which contacts still need an invitation for a given event and releases them in batches over time. See How invitations are batched and sent.

Domain health report. A daily scan of a sending domain's email authentication records, SPF, DKIM, and DMARC, plus blocklist checks. It flags problems that hurt deliverability before they cost you inbox placement. See Domain health reports.

Domain-wide delegation (DWD). The Google Workspace setting that lets your service account act as your users' mailboxes. You grant it in your Workspace admin console with three exact scopes: https://www.googleapis.com/auth/gmail.send, https://www.googleapis.com/auth/gmail.modify, and https://www.googleapis.com/auth/calendar. See Grant domain-wide delegation and scopes.

E#

Enrollment. One contact's journey through one email sequence. When you add a contact to a cold email campaign, Tantra creates an enrollment that walks them step by step. See Enrollment lifecycle and statuses.

Enrollment status. The current state of an enrollment. The values are active, paused, completed, replied, bounced, unsubscribed, and failed. A reply, a bounce, or an unsubscribe stops the sequence for that contact. See Enrollment lifecycle and statuses.

G#

Gmail capable / calendar-only. Two capabilities a connected sender can have. A Gmail capable sender can send cold email. A calendar-only sender can create calendar invitations but cannot send email, usually because domain-wide delegation was granted for calendar but not Gmail. This is normal, not an error. See Sender connection states explained.

L#

Lead stage. A label Tantra assigns to a contact based on their engagement, so you can sort your pipeline. The stages are new, contacted, engaged, replied, positive, negative, meeting_booked, converted, lost, and unsubscribed. See Manage leads, stages, and scores.

M#

MCP server. The Tantra MCP server, a small program that exposes Tantra as tools inside AI clients like Claude or Cursor. It authenticates with an API key and talks to the Tantra API on your behalf. See Connect the Tantra MCP server.

Merge tag. A placeholder in your copy that Tantra replaces with a contact's data before sending. Write them in double braces, for example `{{firstName}}` or a dotted path like `{{contact.company}}`. Unknown tags resolve to an empty string. See Merge tags and spintax.

O#

One-click unsubscribe. A standards-based unsubscribe link and header that lets a recipient opt out in a single click, straight from Gmail's list-header controls. Confirming it adds the address to your suppression list. See One-click unsubscribe.

P#

Personalization. Tantra tailoring your copy to each recipient. It takes a text snapshot of the recipient's public website and asks your chosen AI model to write copy that fits them. Contacts on personal webmail addresses are skipped and fall back to the plain template. See AI personalization for email and calendar.

Q#

Quarantine. A holding state a contact or enrollment can enter when validation finds a problem, such as a syntactically bad address or a role address, so it is not sent to. Quarantined contacts stay out of the send path. See Contact validation and quarantine.

R#

Reply intent. The category Tantra assigns to an inbound reply so you can triage fast. The values are interested, not_interested, objection_pricing, objection_timing, unsubscribe_request, referral, ooo, auto_response, and other. See Reply intents explained.

RSVP. A prospect's response to a calendar invitation, one of accepted, declined, tentative, or no reply. In a calendar campaign the RSVP is your main engagement metric. See Track RSVPs and campaign results.

S#

Scope. A label you attach to an API key, such as campaigns:read or contacts:write, to describe what it is meant for. Scopes are stored as metadata. They do not currently limit what a key can access. See Create and manage API keys.

Sender. One of your mailboxes that Tantra sends from, for example jordan@yourcompany.com. You add senders, then Tantra verifies each one against your service accounts. See Add and verify your senders.

Sending window. The hours and days when a cold email sequence is allowed to send. Outside the window, due steps wait rather than send, so your outreach lands during working hours. See Sending windows and daily limits.

Sequence. The ordered set of email steps in a cold email campaign. Each enrolled contact moves through the sequence one step at a time. See Build an email sequence.

Sequence step. A single message in a sequence, with its own delay before it sends and its own personalization mode, either a fixed template or AI-personalized. See Sequence steps, delays, and personalization modes.

Service account. A Google identity you create in your own Google Cloud project and upload to Tantra. Combined with domain-wide delegation, it lets Tantra send as your mailboxes with short-lived tokens, so Tantra never holds a password. See Create a Google service account.

Smart calendar campaign. The campaign type you create in the calendar engine. You pick contacts, senders, and event details, and Tantra creates the events and sends the invitations in batches. See Create a smart calendar campaign.

Spintax. A way to vary wording so each recipient sees a slightly different phrasing. Write choices in braces separated by pipes, for example `{Hi|Hello|Hey}`. Tantra picks one deterministically per recipient, so a re-send stays consistent. See Merge tags and spintax.

Suppression. Tantra's do-not-contact list. Any address on it is skipped before every send. Unsubscribes, hard bounces, and manual additions land here. See Suppression lists and unsubscribes.

T#

Tracking domain. A subdomain of yours, set up with a CNAME record, that Tantra uses in tracked click links instead of a shared domain. It keeps your links on your own brand and helps deliverability. See Set up a custom tracking domain.

U#

Unsubscribe. A recipient opting out of your emails. When someone unsubscribes, their address is added to suppression and any active enrollment for them stops. See Suppression lists and unsubscribes.

W#

Warmup. A gradual ramp-up that sends low-volume, peer-to-peer messages between mailboxes to build sending reputation before heavy outreach. See Warm up your sending mailboxes.

Webhook. An HTTP endpoint you register so Tantra can notify your systems when something happens, such as a reply or an RSVP change. See Receive outbound webhooks.
