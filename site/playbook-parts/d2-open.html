Build Every Element: The Whole Funnel

Today you build every element in one go: outreach templates for every channel, the registration page, reminders, the live session, follow-ups, the newsletter and the post-event sequence. Work stage by stage, S1 to S6. You're done when every page, message and trigger exists and someone else could run it.

◆ Build Order

Warm the domains now, switch traffic on last. New sending domains need 2 to 3 weeks of warm-up, so that clock starts today. But traffic sent into a half-built funnel burns a list you can't email again.

  1. Confirm your outreach domains are warming (S1, Task S1.1). Start them now if you didn't connect them on Day 1.
  2. Write the outreach templates (S1, Task S1.2), then build S2 to S6.
  3. Switch traffic on only when S2 to S5 are live and a test contact has passed through them.

Install Claude Code now (Day 3 Step 1): today's tool cells use it to draft and build. Any AI assistant works for the writing tasks.
